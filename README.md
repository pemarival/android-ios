# android-ios

Crear proyecto

```
npx create-expo-app mi-app
```

Escoger la versión 54

Entrar a la carpeta 

```
cd mi-app
```

Iniciar aplicación 

```
npm start
```

Correr en android

```
npm run android
```

Correr en ios

```
npm run ios
```

Correr en web

```
npm run web
```
